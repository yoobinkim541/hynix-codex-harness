# Written Answer Prep

The follow-up written section is answered by the human without AI. Prepare them to explain the work in their own words.

Create `WHY_SUMMARY.md` (Korean, plain words, no jargon dumps):

```
# 5줄 요약
1. 문제 정의: 무엇을 왜 이 문제로 봤나
2. 접근: 선택한 방법과 버린 대안 (D#)
3. 결과: 실제로 만든 것과 동작 범위
4. 검증: 무엇을 어떻게 확인했나 (숫자 포함)
5. 한계/다음: 남은 한계와 시간이 더 있으면 할 일

# 예상 질문 3개와 핵심 답 (각 2줄)
# 꼭 기억할 숫자/파일명
```

Rules: every line must be traceable to REQUIREMENTS/DECISIONS/REPORT. No new claims. Keep under 40 lines so it can be read in 3 minutes.
